# The Oasis Academy — Panjgur

A modern, responsive academic website concept for **The Oasis Academy, Panjgur, Balochistan**.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Framer Motion
- Lucide icons
- Plain CSS design system (no Tailwind dependency)

## Pages

- Home
- About
- History
- Academics
- Admissions
- Gallery
- Contact

## Research approach

Historical content is based on publicly accessible sources including the archived Oasis Academy Panjgur WordPress site, Balochistan education reporting, and recent Makran Times references. Older phone numbers, hours and photos are explicitly labelled archival so they are not mistaken for verified current operational details.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Gallery

The site references public archival photographs hosted on the academy's older WordPress gallery. The Next.js config allows only that image host.

## Before an official launch

The academy should confirm current admissions, grade levels, fees, contact number, operating hours, leadership, current campus photos and the exact official logo artwork.
